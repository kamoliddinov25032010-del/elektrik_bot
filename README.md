# ⚡ Elektrik Montaj CRM Bot

Telegram bot orqali elektr montaj ishlarini boshqarish tizimi.

## 🎯 Funksiyalar

### Mijoz uchun
- 📝 Zakaz berish (rasm, video, lokatsiya bilan)
- 📋 Zakazlar tarixi va holati
- 💳 Qarzni ko'rish
- 💰 Narxlar
- 🖼 Portfolio

### Usta uchun
- 📦 Zakazlarni boshqarish
- 🧱 Materiallar hisobi
- 💳 To'lovlarni qabul qilish
- 💸 Xarajatlar
- 📊 Hisobotlar (Excel)

### Admin uchun
- 👷 Ustalarni boshqarish
- 👥 Mijozlar bazasi
- 📈 Statistika
- 📣 Ommaviy xabar yuborish

## 🛠 Texnologiyalar

- Python 3.11+
- Aiogram 3.x
- SQLite (aiosqlite)
- OpenPyXL
